# 🌤️ Weather App

## Description
A simple weather application that allows users to search for cities and view current weather conditions and forecasts for the next 5 days.

## Features
- Search for a city.
- Display city name and country.
- Display current temperature (°C).
- Display weather conditions.
- Display humidity (%).
- Display wind speed (km/h).
- Show weather forecasts for the next 5 days.
- Display loading and error messages.
- Support multiple cities.

## Technologies
- HTML5
- CSS3
- JavaScript
- Fetch API
- Open-Meteo API
- Git & GitHub

## API
This project uses **Open-Meteo API**.

- [Geocoding API](https://open-meteo.com/en/docs/geocoding-api)
- [Weather Forecast API](https://open-meteo.com/en/docs)
